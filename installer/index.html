Update your ESP32 from GitHub.
Without cables.

Set it up once, then just change your code. Each change is built on GitHub, and every board you own installs it over WiFi.

1

Create your project

You get your own copy of the starter project on GitHub, with a blinking-LED example. Keep it Public and click Create repository.

Create my project on GitHub

Free GitHub account needed. You won't install anything on your computer.

2

Install on your board

Plug the ESP32 into this computer over USB and click Install. Use Chrome or Edge. Supported: ESP32, ESP32-S2, ESP32-S3, ESP32-C3 and ESP32-C6 with 4 MB of flash or more.

This browser can't talk to USB devices. Please open this page in Chrome or Edge on a computer. This page must be opened over https.

Won't connect? Hold the board's BOOT button while you click Install, or try another USB cable (some only charge).

3

Connect it

On your phone, join the WiFi network OTA-Setup-XXXX. A setup page opens (if it doesn't, go to 192.168.4.1). Choose your WiFi network and paste your project's link:

Edit code See builds

Your board remembers it. To change it later, hold BOOT for 1 second right after power-on.

✓

Now just change your code

Open firmware/firmware.ino in your project on GitHub, click the pencil, edit, then Commit changes. GitHub builds it in a few minutes. Your board installs it the next time it restarts, or within 5 minutes while it's running.

Questions

Can I still upload with the Arduino IDE? Yes. Keep partitions.csv next to your sketch and the updater survives.

What if a build is broken? The board keeps running the version it has. Fix the code and push again.

Is it safe? Boards only install builds from your repo, downloaded over HTTPS, and check every file before using it. For extra protection, turn on signed builds (see your project's README).
